The Local Dungeon

Six rooms, four treasures, one tiny garden.
Beneath your quiet street — under the laundromat, the corner bakery, the old parking garage — there is a door that none of the neighbors will name. It has a keyhole for a memory, and it opens from the inside. Welcome to the Local Dungeon: a rusted key, a stubborn lever, and one very small garden at the bottom.
How to Play
  • look or examine <thing> — describe the room or an object
  • go <direction> (or just n, s, e, w) — move between rooms
  • take <thing> / grab — pick up an item
  • use <thing> — pull the lever, light the torch, turn the key
  • drop <thing> — leave an item behind
  • inventory / inv — list what you’re carrying
  • help — show this command list inside the console
  • Up / Down arrow keys replay your command history. Click the console to skip the typewriter effect.
