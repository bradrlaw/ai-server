The Local Dungeon

A tiny text adventure. Mind the cobwebs.

Beneath the old mill, something stirs…

For generations, the villagers ignored the mossy stone stairs behind the abandoned mill. Then last Tuesday, a golden light began flickering below, and someone smelled fresh bread. You volunteered. Nobody else did.

How to Play — Available Commands
look / l

Describe your current surroundings.

look at <thing> / x <thing>

Examine an item or feature closely.

go north / n / s / e / w

Move through an exit. Single letters work too.

take <item> / grab <item>

Pick up an item lying in the room.

use <item>

Put something to work — levers welcome.

inventory / inv / i

List everything you're carrying.

help

Show this command list inside the console.
