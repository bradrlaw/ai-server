FAQ

Straight answers

Any machine with 16 GB of RAM runs 7–8B quantized models acceptably on CPU alone. With 8 GB of VRAM (or a Mac with 16 GB unified memory) you'll get genuinely fast responses. During install, LocalMind benchmarks your system and tells you exactly which model sizes will feel snappy versus sluggish — before you download anything.

LocalMind is a full application layer, not just a runner: verified model curation with checksums, document and PDF context loading, a polished chat experience with persistent history, custom presets, and — on Pro and Studio — fine-tuning workflows and multi-GPU inference. It uses the same proven runtimes under the hood, so nothing you already know goes to waste.

You're paying for the software, not the inference — inference is always free and always yours. Subscriptions fund the curated model library, ongoing performance work for new chips, the API server, document ingestion, and fine-tuning tools. Your prompts, outputs, and models never leave your machine on any plan.

The library launches with 300+ models across the Llama, Mistral, Qwen, Gemma, Phi, and DeepSeek families in GGUF and MLX formats — all with verified checksums. You can also paste any Hugging Face repo ID to pull models that aren't in the curated catalog, as long as they're in a supported format.

No. LocalMind ships with a hard "offline mode" toggle that blocks all network access at the application level — you can watch it work with any firewall tool. Telemetry is off by default and, when enabled, sends only anonymous crash reports. Model downloads are the only intentional network request, and they're signed and checksum-verified.
