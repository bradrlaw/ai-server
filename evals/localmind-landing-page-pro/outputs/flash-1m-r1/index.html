FAQ

Questions, answered honestly.

Almost anything modern works. A 16 GB laptop with Apple Silicon or an NVIDIA GPU can run 7–13B models at reading speed. 32 GB gets you into 30B territory, and LocalMind's GPU cluster mode can pool multiple machines for 70B models. During setup, LocalMind benchmarks your hardware and shows realistic tokens-per-second estimates for every model before you download it.
Those are excellent runtimes, and LocalMind is built on the same open-source foundations. The difference is the full product around the engine: a curated and safety-vetted model library, built-in private document RAG with citations, multi-machine clustering, fine-tuning workflows, and a polished chat experience designed for non-engineers. Think runtime versus finished application.
Model weights are downloaded once from verified sources with checksum validation, then stored wherever you choose — including external drives. A typical 8B quantized model is around 4.5–5 GB; a 70B model lands near 40 GB. Downloads are resumable, and LocalMind shows disk usage per model so you're never surprised.
Nothing is held hostage. All chats, document indexes, and models live on your disk in open formats. Downgrading to Free simply disables Pro features like unlimited collections and the API server — your data stays intact and instantly available again if you resubscribe. We physically cannot delete or lock anything, because we never have a copy.
No analytics, no crash telemetry, no usage tracking. The only outbound connections are ones you explicitly trigger: downloading a model or checking for app updates — and both can be disabled in settings, with updates installable from a signed file on a USB stick. There's a network monitor in Settings that shows every connection attempt in real time, because trust is nice but verifiable is better.
